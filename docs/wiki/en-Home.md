**BetterVanilla+ 1.1.0 | Minecraft 26.3 / 26.4 Snapshot 7 | Fabric**

A collection of vanilla-inspired features: craftable elevators, cauldron and beacon interactions, and administration tools for players and villagers.

## Get started in three steps

1. Install Fabric Loader and Fabric API for the Minecraft version matching your JAR.
2. Place BetterVanilla+ in `mods` on the server and every connecting client. For singleplayer, install it in your game profile.
3. Enter a world and craft an elevator, or use `/gameset` with the required permissions.

## Features

- **Elevators:** 29 variants with dedicated textures, individual recipes, a creative tab and vertical teleportation.
- **Cauldrons:** turn dirt into mud and concrete powder into matching concrete in water cauldrons.
- **Beacons:** a golden apple on a fully built beacon with Regeneration grants Saturation V to nearby players.
- **Administration:** personal KeepInventory and an interactive trade editor for the nearest villager.

The topic pages explain conditions and limits. Version 1.1.0 supports Minecraft 26.3 and 26.4 Snapshot 7.
