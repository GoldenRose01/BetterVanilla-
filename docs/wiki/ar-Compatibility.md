|---|---|
| Minecraft Java | 26.3 أو 26.4 Snapshot 7 |
| محمّل المود | Fabric Loader متوافق مع JAR المختار |
| API | Fabric API لإصدار Minecraft نفسه |
| Java | 25 أو أحدث |
| اللعب الجماعي | المود على الخادم والعملاء |

توجد نسختان منفصلتان أدناه. استخدم المطابقة لإصدار Minecraft فقط مع Fabric API المناسب. لا تخلط اللقطات التجريبية أو API أو JAR من إصدارات مختلفة.

تستخدم خامات المصاعد ونماذجها موارد مخصصة؛ حزم Vanilla لا تغيّرها تلقائيًا. يمكن وضع استبدالات صريحة تحت `assets/elevators/`.
