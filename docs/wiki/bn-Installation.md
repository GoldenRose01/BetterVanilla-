## প্রয়োজনীয়তা

- নির্বাচিত JAR অনুযায়ী Minecraft Java **26.3** অথবা **26.4 Snapshot 7**।
- গেমের সঙ্গে সামঞ্জস্যপূর্ণ Fabric Loader।
- একই Minecraft সংস্করণের Fabric API।
- Java 25 বা নতুন।

## ইনস্টল করা

1. নির্বাচিত Minecraft সংস্করণের Fabric Loader ইনস্টল করুন।
2. সামঞ্জস্যপূর্ণ Fabric API `mods`-এ যোগ করুন।
3. BetterVanilla+ 1.1.0-এর **মাত্র একটি** JAR `mods`-এ কপি করুন।
4. সংশ্লিষ্ট Fabric প্রোফাইল দিয়ে Minecraft চালু করুন।

নিচের ডাউনলোড থেকে একটি বেছে নিন; একই প্রোফাইলে দুটো ইনস্টল করবেন না।

## সার্ভার ও ক্লায়েন্ট

লিফট ব্যবহার ও কাস্টম আইটেম দেখতে সার্ভার এবং প্রতিটি ক্লায়েন্টে মড লাগবে। একক খেলায় অন্তর্নির্মিত সার্ভার স্থানীয় প্রোফাইলের ইনস্টলেশন ব্যবহার করে। একই পরিবেশগুলোতে Fabric API-ও থাকতে হবে।

কমান্ড এবং গ্রামবাসীর পরিবর্তন সার্ভারে কার্যকর হয়। লিফটের সক্রিয়তার কণা ক্লায়েন্টের প্রভাব; মড ইনস্টল করা খেলোয়াড়রা তা দেখেন।

## বিল্ড করা

JDK 25 থাকলে Windows-এ `gradlew.bat build` চালান। উন্নয়নের JAR তৈরি হয় `build/libs/`-এ; বিতরণযোগ্য বিল্ডগুলো `jar/`-এ আছে।
