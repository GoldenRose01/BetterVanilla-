## 要求

- Minecraft Java **26.3** 或 **26.4 Snapshot 7**，与所选 JAR 一致。
- 与游戏版本兼容的 Fabric Loader。
- 相同 Minecraft 版本的 Fabric API。
- Java 25 或更高版本。

## 安装步骤

1. 安装所选 Minecraft 版本的 Fabric Loader。
2. 将匹配的 Fabric API 加入 `mods`。
3. 将**一个** BetterVanilla+ 1.1.0 JAR 放入 `mods`。
4. 使用对应的 Fabric 游戏配置启动 Minecraft。

选择下方其中一个下载，不要在同一配置中安装两个版本。

## 服务器与客户端

要使用电梯和查看自定义物品，服务器及每个客户端都必须安装本模组。单人游戏的内置服务器共用本地配置中的安装。相同环境中也必须安装 Fabric API。

命令和村民修改在服务器端执行。电梯活动粒子是客户端效果，仅安装模组的玩家可见。

## 构建

安装 JDK 25 后，在 Windows 上运行 `gradlew.bat build`。开发用 JAR 输出到 `build/libs/`，发行构建位于 `jar/`。

- [Minecraft 26.3 — JAR](../../jar/BetterVanilla+-1.1.0-26.3.jar)
- [Minecraft 26.4 Snapshot 7 — JAR](../../jar/BetterVanilla+-1.1.0-26.4-snapshot-7.jar)
