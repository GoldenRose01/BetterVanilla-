| موڈ لوڈر | منتخب JAR سے ہم آہنگ Fabric Loader |
| API | اسی Minecraft نسخے کا Fabric API |
| Java | 25 یا نیا |
| ملٹی پلیئر | سرور اور کلائنٹس پر موڈ |

نیچے دو الگ بلڈ ہیں۔ صرف اپنے Minecraft نسخے کا بلڈ اور متعلقہ Fabric API استعمال کریں۔ مختلف نسخوں کے اسنیپ شاٹ، API یا JAR نہ ملائیں۔

لفٹوں کے ٹیکسچر اور ماڈل اپنے وسائل استعمال کرتے ہیں۔ Vanilla ریسورس پیک خودکار طور پر اثر نہیں ڈالتے؛ واضح متبادل `assets/elevators/` کے تحت رکھے جا سکتے ہیں۔
