## Requisitos

- Minecraft Java **26.3** o **26.4 Snapshot 7**, según el JAR elegido.
- Fabric Loader compatible con el juego.
- Fabric API para la misma versión de Minecraft.
- Java 25 o posterior.

## Instalación

1. Instala Fabric Loader para la versión elegida.
2. Añade Fabric API compatible a `mods`.
3. Copia **un solo** JAR de BetterVanilla+ 1.1.0 a `mods`.
4. Inicia Minecraft con el perfil Fabric correspondiente.

Elige una de las descargas de abajo. No instales ambas en el mismo perfil.

## Servidor y clientes

Para usar ascensores y ver objetos personalizados, instala la mod en el servidor y todos los clientes. En un jugador, el servidor integrado comparte la instalación del perfil local. Fabric API debe estar en esos mismos entornos.

Los comandos y cambios de aldeanos se ejecutan en el servidor. Las partículas de actividad son un efecto del cliente, visible para quienes tengan la mod.

## Compilación

Con JDK 25, ejecuta `gradlew.bat build` en Windows. El JAR de desarrollo se genera en `build/libs/`; las versiones distribuidas están en `jar/`.
