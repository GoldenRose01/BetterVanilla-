# अनुकूलता

भाषाएँ: [Italiano](Compatibilita.md) | [English](en-Compatibility.md) | [Español](es-Compatibility.md) | [简体中文](zh-Compatibility.md) | [हिन्दी](hi-Compatibility.md) | [العربية](ar-Compatibility.md) | [Português](pt-Compatibility.md) | [বাংলা](bn-Compatibility.md) | [Русский](ru-Compatibility.md) | [اردو](ur-Compatibility.md)

| घटक | आवश्यकता |
|---|---|
| Minecraft Java | 26.3 या 26.4 Snapshot 7 |
| मॉड लोडर | JAR से अनुकूल Fabric Loader |
| API | उसी Minecraft संस्करण का Fabric API |
| Java | 25 या नया |
| मल्टीप्लेयर | सर्वर और क्लाइंट दोनों पर मॉड |

नीचे दो अलग बिल्ड हैं। केवल अपने Minecraft का बिल्ड और संबंधित Fabric API चुनें। अलग संस्करणों के स्नैपशॉट, API या JAR न मिलाएँ।

लिफ्ट टेक्सचर और मॉडल अपने संसाधन इस्तेमाल करते हैं। Vanilla रिसोर्स पैक उन्हें अपने-आप नहीं बदलते; स्पष्ट ओवरराइड `assets/elevators/` में रख सकते हैं।
