| Componente | Requisito |
|---|---|
| Minecraft Java | 26.3 o 26.4 Snapshot 7 |
| Cargador | Fabric Loader compatible con el JAR |
| API | Fabric API para la misma versión de Minecraft |
| Java | 25 o posterior |
| Multijugador | Mod en servidor y clientes |

Hay dos compilaciones enlazadas abajo. Usa solo la de tu versión y añade la Fabric API correspondiente. No mezcles snapshots, API y JAR de versiones diferentes.

Texturas y modelos de ascensores usan recursos propios. Los paquetes Vanilla no los alteran automáticamente; puedes sustituirlos explícitamente bajo `assets/elevators/`.
