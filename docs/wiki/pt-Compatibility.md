# Compatibilidade

Idiomas: [Italiano](Compatibilita.md) | [English](en-Compatibility.md) | [Español](es-Compatibility.md) | [简体中文](zh-Compatibility.md) | [हिन्दी](hi-Compatibility.md) | [العربية](ar-Compatibility.md) | [Português](pt-Compatibility.md) | [বাংলা](bn-Compatibility.md) | [Русский](ru-Compatibility.md) | [اردو](ur-Compatibility.md)

| Componente | Requisito |
|---|---|
| Minecraft Java | 26.3 ou 26.4 Snapshot 7 |
| Carregador | Fabric Loader compatível com o JAR |
| API | Fabric API da mesma versão de Minecraft |
| Java | 25 ou superior |
| Multijogador | Mod no servidor e nos clientes |

Há duas compilações distintas abaixo. Use apenas a da sua versão de Minecraft e a Fabric API correspondente. Não misture snapshots, APIs ou JARs de versões diferentes.

Texturas e modelos dos elevadores usam recursos próprios. Pacotes Vanilla não os alteram automaticamente; substituições explícitas podem ser colocadas em `assets/elevators/`.

- [Minecraft 26.3 — JAR](../../jar/BetterVanilla+-1.1.0-26.3.jar)
- [Minecraft 26.4 Snapshot 7 — JAR](../../jar/BetterVanilla+-1.1.0-26.4-snapshot-7.jar)
