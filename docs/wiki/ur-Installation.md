## ضروریات

- منتخب JAR کے مطابق Minecraft Java **26.3** یا **26.4 Snapshot 7**۔
- گیم سے ہم آہنگ Fabric Loader۔
- اسی Minecraft نسخے کا Fabric API۔
- Java 25 یا نیا۔

## تنصیب

1. منتخب Minecraft نسخے کے لیے Fabric Loader نصب کریں۔
2. موزوں Fabric API کو `mods` میں شامل کریں۔
3. BetterVanilla+ 1.1.0 کا **صرف ایک** JAR، `mods` میں کاپی کریں۔
4. متعلقہ Fabric پروفائل سے Minecraft شروع کریں۔

نیچے دیے گئے ڈاؤن لوڈ میں سے ایک منتخب کریں؛ دونوں ایک پروفائل میں نصب نہ کریں۔

## سرور اور کلائنٹ

لفٹیں استعمال کرنے اور مخصوص اشیا دیکھنے کے لیے سرور اور ہر کلائنٹ پر موڈ نصب ہونا چاہیے۔ اکیلے کھیل میں اندرونی سرور مقامی پروفائل کی تنصیب استعمال کرتا ہے۔ انہی ماحولوں میں Fabric API بھی ضروری ہے۔

کمانڈز اور دیہاتیوں کی تبدیلیاں سرور پر چلتی ہیں۔ لفٹ کی سرگرمی کے ذرات کلائنٹ کا اثر ہیں، جو موڈ نصب کرنے والے کھلاڑی دیکھتے ہیں۔

## پروجیکٹ بنانا

JDK 25 کے ساتھ Windows پر `gradlew.bat build` چلائیں۔ ترقیاتی JAR، `build/libs/` میں بنتا ہے؛ تقسیم شدہ بلڈ `jar/` میں ہیں۔
