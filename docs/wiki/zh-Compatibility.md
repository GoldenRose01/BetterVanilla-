# 兼容性

语言: [Italiano](Compatibilita.md) | [English](en-Compatibility.md) | [Español](es-Compatibility.md) | [简体中文](zh-Compatibility.md) | [हिन्दी](hi-Compatibility.md) | [العربية](ar-Compatibility.md) | [Português](pt-Compatibility.md) | [বাংলা](bn-Compatibility.md) | [Русский](ru-Compatibility.md) | [اردو](ur-Compatibility.md)

| 组件 | 要求 |
|---|---|
| Minecraft Java | 26.3 或 26.4 Snapshot 7 |
| 模组加载器 | 与所选 JAR 兼容的 Fabric Loader |
| API | 相同 Minecraft 版本的 Fabric API |
| Java | 25 或更高版本 |
| 多人游戏 | 服务器和客户端均安装模组 |

下方提供两个独立构建。仅使用对应 Minecraft 版本的构建及 Fabric API，不要混用不同版本的快照、API 或 JAR。

电梯纹理和模型使用专用资源。替换原版纹理的资源包不会自动影响电梯；可在 `assets/elevators/` 中明确覆盖。

- [Minecraft 26.3 — JAR](../../jar/BetterVanilla+-1.1.0-26.3.jar)
- [Minecraft 26.4 Snapshot 7 — JAR](../../jar/BetterVanilla+-1.1.0-26.4-snapshot-7.jar)
