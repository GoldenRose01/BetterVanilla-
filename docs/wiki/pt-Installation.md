## Requisitos

- Minecraft Java **26.3** ou **26.4 Snapshot 7**, conforme o JAR escolhido.
- Fabric Loader compatível com o jogo.
- Fabric API para a mesma versão de Minecraft.
- Java 25 ou superior.

## Instalar

1. Instale Fabric Loader para a versão escolhida.
2. Adicione Fabric API compatível a `mods`.
3. Copie **apenas um** JAR de BetterVanilla+ 1.1.0 para `mods`.
4. Inicie Minecraft com o perfil Fabric correspondente.

Escolha um dos downloads abaixo; não instale ambos no mesmo perfil.

## Servidor e clientes

Instale a mod no servidor e em todos os clientes para usar elevadores e ver itens personalizados. No modo individual, o servidor integrado compartilha a instalação local. Fabric API deve estar presente nos mesmos ambientes.

Comandos e alterações nos aldeões são executados no servidor. As partículas de atividade são um efeito do cliente, visível para quem tem a mod instalada.

## Compilar

Com JDK 25, execute `gradlew.bat build` no Windows. O JAR de desenvolvimento fica em `build/libs/`; as versões distribuídas ficam em `jar/`.

- [Minecraft 26.3 — JAR](../../jar/BetterVanilla+-1.1.0-26.3.jar)
- [Minecraft 26.4 Snapshot 7 — JAR](../../jar/BetterVanilla+-1.1.0-26.4-snapshot-7.jar)
