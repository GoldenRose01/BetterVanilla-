# Compatibility

Languages: [Italiano](Compatibilita.md) | [English](en-Compatibility.md) | [Español](es-Compatibility.md) | [简体中文](zh-Compatibility.md) | [हिन्दी](hi-Compatibility.md) | [العربية](ar-Compatibility.md) | [Português](pt-Compatibility.md) | [বাংলা](bn-Compatibility.md) | [Русский](ru-Compatibility.md) | [اردو](ur-Compatibility.md)

| Component | Requirement |
|---|---|
| Minecraft Java | 26.3 or 26.4 Snapshot 7 |
| Mod loader | Fabric Loader compatible with the chosen JAR |
| API | Fabric API for the same Minecraft version |
| Java | 25 or later |
| Multiplayer | Mod installed on both server and clients |

Two separate builds are available below. Use only the one for your Minecraft version and add the corresponding Fabric API. Do not mix snapshots, APIs or JARs intended for different versions.

Elevator textures and models use dedicated resources: vanilla resource-pack replacements do not automatically affect elevators. Explicit overrides can be placed under `assets/elevators/`.

- [Minecraft 26.3 — JAR](../../jar/BetterVanilla+-1.1.0-26.3.jar)
- [Minecraft 26.4 Snapshot 7 — JAR](../../jar/BetterVanilla+-1.1.0-26.4-snapshot-7.jar)
