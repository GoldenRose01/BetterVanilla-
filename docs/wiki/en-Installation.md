## Requirements

- Minecraft Java **26.3** or **26.4 Snapshot 7**, matching the chosen JAR.
- Fabric Loader compatible with the game version.
- Fabric API for the same Minecraft version.
- Java 25 or later.

## Install

1. Install Fabric Loader for your chosen Minecraft version.
2. Add the matching Fabric API to `mods`.
3. Copy **one** BetterVanilla+ 1.1.0 JAR into `mods`.
4. Start Minecraft with the corresponding Fabric profile.

Choose one download below; do not install both in the same profile.

## Server and client

Install the mod on the server and every client to use elevators and see custom items. In singleplayer, the integrated server shares the local profile installation. Fabric API must be present in the same environments.

Commands and villager changes run on the server. Elevator activity particles are a client effect visible to players with the mod installed.

## Build

With JDK 25 installed, run `gradlew.bat build` on Windows. The development JAR is created in `build/libs/`; distributed builds are in `jar/`.

- [Minecraft 26.3 — JAR](../../jar/BetterVanilla+-1.1.0-26.3.jar)
- [Minecraft 26.4 Snapshot 7 — JAR](../../jar/BetterVanilla+-1.1.0-26.4-snapshot-7.jar)
