# Release 1.1.0

Languages: [Italiano](Versione-1.1.0.md) | [English](en-Release-1.1.0.md) | [Español](es-Release-1.1.0.md) | [简体中文](zh-Release-1.1.0.md) | [हिन्दी](hi-Release-1.1.0.md) | [العربية](ar-Release-1.1.0.md) | [Português](pt-Release-1.1.0.md) | [বাংলা](bn-Release-1.1.0.md) | [Русский](ru-Release-1.1.0.md) | [اردو](ur-Release-1.1.0.md)

Version **1.1.0** brings together elevator features, new interactions and administration tools in BetterVanilla+.

## Included features

- 29 craftable elevators with dedicated textures, a creative tab, vertical teleportation and activity particles.
- Enderman and Shulker sounds on every successful teleport.
- Water-cauldron conversions: dirt into mud and concrete powder into matching concrete.
- Saturation V from a golden apple on a level 4 beacon with Regeneration.
- A command to retain an individual player's inventory and experience.
- An interactive editor to create, edit and delete the nearest villager's trades.

## Available builds

- Minecraft 26.3: `BetterVanilla+-1.1.0-26.3.jar`
- Minecraft 26.4 Snapshot 7: `BetterVanilla+-1.1.0-26.4-snapshot-7.jar`

Use Fabric API matching the game version. See installation for requirements and home for feature guides.
