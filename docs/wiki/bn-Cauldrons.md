# কড়াই

আইটেম **পানিভরা কড়াইয়ে** ফেলুন। পুরো স্ট্যাক একই সংখ্যক ফলের আইটেমে বদলে যায়।

| ফেলা আইটেম | ফল |
|---|---|
| মাটি | কাদা |
| রুক্ষ মাটি | কাদা |
| শিকড়যুক্ত মাটি | কাদা |
| যেকোনো রঙের কংক্রিটের গুঁড়া | একই রঙের কংক্রিট |

পানি লাগবেই; খালি বা লাভাভরা কড়াই কাজ করে না। জগতে ফেলে দেওয়া আইটেম এন্টিটি প্রক্রিয়াকরণ করা হয়; ইন্টারফেস বা ক্রাফটিং রেসিপি লাগে না।
