# Calderoni

Getta gli oggetti in un **calderone d’acqua** per attivare le conversioni. L’intera pila viene trasformata nello stesso numero di oggetti di uscita.

| Oggetto gettato | Risultato |
|---|---|
| Terra | Fango |
| Terra sterile | Fango |
| Terra con radici | Fango |
| Polvere di cemento di qualsiasi colore | Cemento dello stesso colore |

Le conversioni richiedono acqua nel calderone; un calderone vuoto o pieno di lava non le attiva. Gli oggetti vengono raccolti come entità nel mondo, quindi non serve usare un’interfaccia o una ricetta di crafting.
