# Совместимость

Языки: [Italiano](Compatibilita.md) | [English](en-Compatibility.md) | [Español](es-Compatibility.md) | [简体中文](zh-Compatibility.md) | [हिन्दी](hi-Compatibility.md) | [العربية](ar-Compatibility.md) | [Português](pt-Compatibility.md) | [বাংলা](bn-Compatibility.md) | [Русский](ru-Compatibility.md) | [اردو](ur-Compatibility.md)

| Компонент | Требование |
|---|---|
| Minecraft Java | 26.3 или 26.4 Snapshot 7 |
| Загрузчик | Fabric Loader, совместимый с JAR |
| API | Fabric API для той же версии Minecraft |
| Java | 25 или новее |
| Сетевая игра | Мод на сервере и клиентах |

Ниже доступны две отдельные сборки. Используйте только соответствующую Minecraft и добавьте нужный Fabric API. Не смешивайте снапшоты, API и JAR разных версий.

Текстуры и модели лифтов используют собственные ресурсы. Замены текстур Vanilla не влияют на них автоматически; явные переопределения размещаются в `assets/elevators/`.

- [Minecraft 26.3 — JAR](../../jar/BetterVanilla+-1.1.0-26.3.jar)
- [Minecraft 26.4 Snapshot 7 — JAR](../../jar/BetterVanilla+-1.1.0-26.4-snapshot-7.jar)
