| উপাদান | প্রয়োজনীয়তা |
|---|---|
| Minecraft Java | 26.3 অথবা 26.4 Snapshot 7 |
| মড লোডার | নির্বাচিত JAR-এর অনুকূল Fabric Loader |
| API | একই Minecraft সংস্করণের Fabric API |
| Java | 25 বা নতুন |
| একাধিক খেলোয়াড় | সার্ভার ও ক্লায়েন্টে মড |

নিচে দুটি আলাদা বিল্ড আছে। নিজের Minecraft-এর বিল্ড ও সংশ্লিষ্ট Fabric API ব্যবহার করুন। ভিন্ন সংস্করণের স্ন্যাপশট, API বা JAR মেশাবেন না।

লিফটের টেক্সচার ও মডেল নিজস্ব রিসোর্স ব্যবহার করে। Vanilla রিসোর্স প্যাক স্বয়ংক্রিয়ভাবে বদলায় না; সরাসরি ওভাররাইড `assets/elevators/`-এ রাখা যায়।
