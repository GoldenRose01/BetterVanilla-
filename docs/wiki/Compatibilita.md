# Compatibilità

| Componente | Requisito |
|---|---|
| Minecraft Java | 26.3 oppure 26.4 Snapshot 7 |
| Mod loader | Fabric Loader compatibile con il JAR scelto |
| API | Fabric API per la stessa versione di Minecraft |
| Java | 25 o successivo |
| Installazione multiplayer | Mod presente sia sul server sia sui client |

Sono disponibili due build distinte: [BetterVanilla+ 1.1.0 per 26.3](../../jar/BetterVanilla+-1.1.0-26.3.jar) e [BetterVanilla+ 1.1.0 per 26.4 Snapshot 7](../../jar/BetterVanilla+-1.1.0-26.4-snapshot-7.jar). Usa solo quella corrispondente alla tua versione di Minecraft e aggiungi Fabric API della stessa versione. Non mischiare snapshot, API e JAR destinati a versioni diverse.

Le texture e i modelli degli ascensori usano risorse dedicate della mod: i resource pack che sostituiscono le texture Vanilla non alterano automaticamente gli ascensori. È possibile crearne override espliciti sotto `assets/elevators/`.
